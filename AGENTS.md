# AGENTS.md

## publik API
- Base URL: https://publikhq.com/api/v1 (OpenAI Chat Completions, Responses, Anthropic Messages)
- Models: publik-fast, publik-balanced, publik-smart only; never a vendor model name
- Sign in with publik: the publik module's gate runs at start-up, before the first screen; it also sends usage telemetry
- Key: per-install `pk_` from POST /installs, stored at the publik credential path; env PUBLIK_API_KEY / PUBLIK_API_BASE_URL override (test builds only, see "Test hooks")
- App token: publik-app-token.txt (public by design, committed) or PUBLIK_APP_TOKEN
- 402: show error.message plus error.top_up_url only
- Never print or log a key
- Docs: https://publikhq.com/llms.txt, https://publikhq.com/developers, https://publikhq.com/skills/api.md

## publik in this repo
- NoScroll calls no AI model: `usesAI = false` (iOS) and `USES_AI = false` (Android). The gate shows Sign in with publik only.
- Gate mode, one build setting: `PUBLIK_GATE_MODE = required | optional` (default `required`). iOS: `ios/Config/App.xcconfig` → Info.plist key `PublikGateMode` (override: `xcodebuild ... PUBLIK_GATE_MODE=optional`). Android: `PUBLIK_GATE_MODE` env or `-PpublikGateMode=optional` → `BuildConfig.PUBLIK_GATE_MODE`. Optional mode: no wall, "Sign in with publik" in Settings (iOS) / Status (Android), usage counting only after sign-in.
- Name (founder decision, Nov 14 2026): the App Store name and the in-app name are "publik NoScroll". The short label under the icon stays "NoScroll", because iOS cuts a 15-character label. Slug `noscroll`, bundle id `app.noscroll` and the scheme do not change.
  - iOS: `APP_NAME = publik NoScroll` in `ios/Config/App.xcconfig` → Info.plist key `AppFullName` → `AppState.appName` and `Publik.appName` (the app's screens, the gate, the purpose strings). `APP_DISPLAY_NAME = NoScroll` → `CFBundleDisplayName` → `AppState.homeScreenName` (the icon label, the widget, "Search for NoScroll"). The App Store name is set in App Store Connect.
  - Android: `app_name` = "NoScroll" (launcher label), `app_name_full` = "publik NoScroll" (the app's screens and the gate).
- publik pages in the app (both systems): only publik's bare "in-app" pages, with no site navigation, footer, prices or plan links. Sign in: the server's `claim_url` plus `in_app=1` (other query items stay; publik redirects to `/in-app/claim/<code>`). Delete account: `/in-app/delete-account`. Privacy: `/in-app/privacy`. iOS builds them in `ios/NoScrollCore/Sources/NoScrollCore/PublikLinks.swift` (tests: `PublikLinksTests`), Android in `Publik.kt` (`inAppClaimUrl`, `deleteAccountUrl`, `privacyUrl`; tests: `PublikLinksTest`). There is no fallback to any other publik page. The wallet poll closes the in-app browser after sign-in.
- App Store release: the gate stays `required`. Availability: all countries (an App Store Connect setting). NoScroll has no purchase link: `usesAI = false`, so the plan screens of the publik module never show.
- Do not name or point to any other app in code comments or UI. The services that NoScroll opens (Instagram, YouTube and the BETA services) are the exception. The MIT attributions in README.md and the `source` fields of the rule bundles stay.
- Rule signing (ed25519): the public key is committed (`keys/rules-signing.pub.pem`, `keys/rules-signing.pub.raw`, and the same 32 bytes in `ios/NoScroll/Resources/rules-signing.pub.raw`). The private key is only in the repo secret `RULES_SIGNING_KEY`; never print it or commit it. A push to `signin-gate` that changes `rules/` or the engine (`engine/src`, `engine/build.mjs`, `engine/package.json`, `engine/pnpm-lock.yaml`) runs `.github/workflows/sign-rules.yml` ("Sign rule bundles"): it signs every bundle, builds the engine, copies the engine and the bundles into the iOS and Android resources (`tools/sync-engine.mjs`) and commits them as github-actions[bot]. That commit starts no workflow, so push the next change on top of it. The `engine` job of `ci.yml` fails when an app copy of `noscroll.js` is not the engine built from `engine/src`. The `signing` job of `ci.yml` verifies them in Node and in Swift. Remote bundles at `rules.noscroll.app` must be signed with the same key.
- iOS: `ios/NoScroll/Publik/Publik.swift` (the module) and `PublikGateView.swift` (its SwiftUI screen and the Settings rows: sign out, delete account, usage counting). `NoScrollApp` in `ios/NoScroll/App/RootView.swift` shows the gate before `RootView` in required mode. Privacy manifest: `ios/NoScroll/PrivacyInfo.xcprivacy`.
- Android: `android/app/src/main/java/app/noscroll/publik/Publik.kt` (a Kotlin port of the module), `PublikGateView.kt` and `PublikSignInActivity.kt` (optional mode). `MainActivity.onCreate` runs the gate before `startApp()` in required mode. `StatusActivity` has the publik rows.
- App token: the "publik app token" build phase (iOS) and `app/build.gradle.kts` (Android) take `PUBLIK_APP_TOKEN` at build time, else `publik-app-token.txt` at the repo root. CI uses the repo secret `PUBLIK_APP_TOKEN`. A release build without a `pat_` token fails: iOS `CONFIGURATION=Release` (the build phase exits 1), Android `preReleaseBuild` (task `checkPublikAppToken`). Debug builds only warn.
- Test hooks: iOS reads `PUBLIK_API_BASE_URL`, `PUBLIK_ORIGIN`, `PUBLIK_TELEMETRY_URL`, `PUBLIK_API_KEY`, `PUBLIK_APP_TOKEN`, `PUBLIK_SELF_TEST`, `PUBLIK_TEST_PRESS` (the gate presses that button once by itself) and `PUBLIK_LAYOUT_PROBE` (the first onboarding screen prints its layout, then the app exits) from the environment or launch arguments only when the Swift flag `PUBLIK_TEST_HOOKS` is on. It is on in Debug and in CI test builds (`xcodebuild ... PUBLIK_TEST_HOOKS=YES`), and off in the App Store Release build (`ios/Config/App.xcconfig`). Android reads the `PUBLIK_` intent extras only when `BuildConfig.DEBUG`.
- Sign out (both systems): stop usage counting, delete the key file first, then revoke the key held in memory in a task that no screen can cancel. iOS excludes the publik folder and the key file from backups. Android has `allowBackup="false"`. Android keeps `Publik.signedInThisProcess`, so a recreated `MainActivity` does not show the gate again.
- Self-test of a built app: iOS Simulator `SIMCTL_CHILD_PUBLIK_SELF_TEST=1 xcrun simctl launch --console-pty booted app.noscroll`; Android `adb shell am start -n app.noscroll/.MainActivity --es PUBLIK_SELF_TEST 1`, then `adb logcat -d -s publik`. It prints `publik self-test: ok noscroll <version>`.
- Test publik: `PUBLIK_API_BASE_URL` (iOS test-hook builds: environment or launch argument `-PUBLIK_API_BASE_URL <url>`; Android debug builds: `--es PUBLIK_API_BASE_URL <url>`).
- iOS screens: `AppRoot` (`ios/NoScroll/App/RootView.swift`) is the one stable root view. The gate, the onboarding and the tabs are content inside it (no root view controller swap, no `fullScreenCover`). The gate hands over only after its in-app browser has closed completely. `.github/scripts/ios-gate-layout-test.sh` checks this in CI with a fake publik (`.github/scripts/fake-publik.py`).
- Offline start (iOS): the key file keeps a "signed in" mark (`claimed`) and the handle. With the mark, the gate passes when publik does not answer (offline, 5xx, 408, 429, a captive portal). Only publik's JSON 401 or a wallet that is not claimed clears it. A fresh install needs publik once.
- iOS appearance: light only (`UIUserInterfaceStyle = Light`), on purpose.
- Sign-in poll (both systems): `PublikPoll` (iOS `ios/NoScrollCore/Sources/NoScrollCore/PublikPoll.swift`, tests `PublikPollTests`; Android `publik/PublikPoll.kt`, tests `PublikPollTest`). It checks GET /wallet every 3 s for 10 minutes on a fixed grid. Each check runs on its own (8 s timeout), so a slow request never moves the next check, and there is no back-off. iOS also checks at once when the app becomes active again or the in-app sign-in page closes (`Publik.pollNow()`). Android checks only in the foreground, and at once when the app comes back.
- App Store build (iOS): `APP_STORE_BUILD = YES` in `ios/Config/App.xcconfig` → Info.plist key `AppStoreBuild` (app and widget) → `AppState.isAppStoreBuild`. `xcodebuild ... APP_STORE_BUILD=NO` gives the full build. The App Store build:
  - ships only the services that were seen working: Instagram, YouTube, TikTok, Facebook, LinkedIn. `AppState.notInStoreBuild` (X, Reddit, Snapchat) has no tile, no switch, no sign-out row and no widget tile. Their rule files stay. Android still lists them.
  - says no "beta" anywhere (guideline 2.2): `Service.beta` is false, so no BETA label, no beta footer and no beta line in How blocking works.
  - shows, for TikTok, Facebook and LinkedIn (`addressOnlyInStoreBuild`), only the switches that block by address (route rules). Their page-part rules are off and have no switch (`AppState.isOffered`).
  - blocks no ads: the ad rules (`sponsored`, `promoted`) default off, the app keeps them off and shows no switch, and the rule lint fails any other rule that points at an ad.
- Links to other sites (iOS): the web view shows only the service's domains (from the bundle's `match`) and the sign-in pages of Google, Apple and Facebook (`ServiceLinks` in NoScrollCore, tests `ServiceLinksTests`). Any other main-frame page opens in the in-app Safari sheet (SFSafariViewController), so the app gives no unrestricted web access.
- Help and support (iOS Settings): publik's bare in-app page `/in-app/support` in the in-app browser (`PublikLinks.supportURL`).
- Sign-in pages: the engine is inert on an auth route and on any page with a password field (`hasPasswordField` in `engine/src/engine.ts`; Facebook serves its login form at "/"). iOS shows one sign on every service: a 44 pt bar under the title, "Sign-in page: NoScroll is paused". A tap explains the pause. The bar goes away when the engine says `ready` on the next page.
- YouTube: the Shorts tab of the current mobile site is `ytm-pivot-bar-item-renderer` with `.pivot-bar-item-tab` and the class `shorts` (bar drawn before the page data) or `pivot-shorts` (bar drawn from the page data). The rule matches both with `[class*='shorts']` (the rule lint reads `.shorts` as a hashed class). It has no link and no aria-label, and it opens `/shorts/` with no video id. `shorts-route` is a route block `^/shorts(/|\?|$)` → `/`, checked on load and on every in-page address change. Fixture: `engine/test/fixtures/youtube-pivot-current.html`. The `youtube-live` job of `ci.yml` runs `probe/probe.spec.ts -g YouTube` in headless WebKit (iPhone profile) against live m.youtube.com with `ios/NoScroll/Resources/noscroll.js` and `rules/youtube.json`.
- Settings (iOS): About has How blocking works (plain words), Blocking rules (the version of each rule list and of the engine), Source code (in the in-app browser) and the line "publik NoScroll <version> (<build>)". Signed out, the publik section shows only Sign in with publik.
- `.github/workflows/publik-test-builds.yml` builds the test artifacts `ios-sim-app` (required mode), `ios-sim-app-optional` (optional mode) and `android-debug-apk`, and runs the self-tests.
